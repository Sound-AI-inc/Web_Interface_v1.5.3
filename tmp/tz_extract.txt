211 РАЗДЕЛ 5. GENERATION FEED (ЛЕНТА РЕЗУЛЬТАТОВ)
212 --------------------------------------------------------------------------------
213  
214 5.1 Поведение ленты
215  
216 После нажатия Generate:
217 1. Composer dock плавно фиксируется внизу (если был по центру — transition bottom).
218 2. В ленте появляется новый блок: User Message (промпт).
219 3. Под ним появляется Generation Card с состоянием Loading.
220 4. После ответа — Loading сменяется на Asset Cards.
221  
222 Лента: flex-column, gap-24px, padding-bottom: 120px (чтобы контент не перекрывался Composer).
223  
224 5.2 User Message Bubble
225  
226 Align: right (flex justify-end)
227 Background: var(--bg-card) с gradient border (1px, primary gradient)
228 Border-radius: 20px 20px 4px 20px
229 Padding: 12px 16px
230 Font: Inter 14px, text-primary
231 Max-width: 70%
232  
233 5.3 Generation Card (состояние Loading)
234  
235 Align: left
236 Background: var(--bg-card)
237 Border-radius: 20px
238 Padding: 16px 20px
239 Width: 100%
240  
241 Содержимое в Loading:
242   - Анимированные shimmer-плашки (skeleton) для 3 ожидаемых assets
243   - Текст: "Generating [TYPE]..." с анимированной точкой
244   - Цвет shimmer: gradient rgba(255,255,255,0.05) → rgba(255,255,255,0.10) → rgba(255,255,255,0.05)
245   - animation: shimmer 1.8s infinite linear
246  
247 5.4 Asset Card (результат)
248  
249 Для каждого сгенерированного файла — отдельная карточка.
250  
251 Карточка Audio Sample:
252   ┌──────────────────────────────────────────────────────┐
253   │  [Waveform visualization — 100% width, 48px height] │
254   │                                                      │
255   │  Filename: Dark Techno Kick 001.wav                  │
256   │  BPM: 135   Key: C minor   Duration: 2.4s            │
257   │                                                      │
258   │  [ ▶  Play]  [Download ↓]  [ ♡  Save]  [Reuse →]        │
259   └──────────────────────────────────────────────────────┘
260  
261   Background: var(--bg-card)
262   Border: 1px solid var(--border-subtle)
263   Border-radius: 20px
264   Padding: 16px 20px
265   Hover: border-color → primary gradient, box-shadow → glow
266  
267 Карточка MIDI:
268   - Иконка MIDI (piano roll icon)
269   - Metadata: Scale, Key, Bars, Time signature
270   - Actions: Preview (MIDI visualizer), Download .mid, Reuse
271  
272 Карточка VST Preset:
273   - Plugin name + иконка
274   - Category tag (Bass / Lead / Pad)
275   - Actions: Copy settings, Download .fxp/.vstpreset, Open in editor
276  
277 5.5 История генераций (Session History)
278  
279 Автоматически: каждый запрос + результаты добавляются в ленту снизу.
280 Прокрутка вверх — видна история сессии.
281 Нет отдельной вкладки в Sidebar для истории чата.
282 Кнопка "Save to Library" на каждой карточке — ручное сохранение лучших результатов.
